# 1d20.com.ua — Український переклад для Plutonium

> Ця гілка містить збірку для Foundry 13 та dnd5e 5.3.x. Для Foundry 14 використовуйте гілку main.

**Український переклад: [1d20.com.ua](https://1d20.com.ua)**

Модуль для Foundry VTT (dnd5e), який імпортує контент через [Plutonium](https://5e.tools) звичайним Ctrl+V і вміє підміняти назву та опис українським перекладом з 1d20.com.ua.

## Встановлення

**[Інструкція зі скріншотами](docs/installation.uk.md)**

1. На стартовому екрані Foundry відкрийте **Add-on Modules → Install Module**.
2. Вставте посилання для своєї версії в **Manifest URL** та натисніть **Install**.
3. Якщо Foundry запропонує встановити **Plutonium** і **libWrapper**, погодьтеся.
4. Запустіть світ dnd5e. У **Module Management / Manage Modules** увімкніть перекладач і Plutonium, потім натисніть **Save Module Settings**.

**Foundry 14:**

```text
https://raw.githubusercontent.com/funteaqueue/1d20-ua-plutonium/main/module.json
```

**Foundry 13** — потрібна **dnd5e 5.3.x**:

```text
https://raw.githubusercontent.com/funteaqueue/1d20-ua-plutonium/main/module-foundry13.json
```

Якщо Plutonium уже встановлений, він має відповідати вашій версії Foundry. Після переходу з Foundry 13 на 14 перевстановіть перекладач за посиланням для 14.

## Використання

**Імпорт із конструктора персонажа:** [команда для консолі та формат JSON](docs/character-builder.uk.md). Ctrl+V готує персонажа через Plutonium і показує звіт перед записом. Імпортер обробляє правила 2014/2024, рівні 1–20, мультиклас, підкласи, раси й підраси, передісторії, риси, закляття, спорядження та власні ресурси. Foundry 13 використовує dnd5e 5.3.x, Foundry 14 — dnd5e 6.x. Це прототип: живий імпорт користувач підтвердив на Foundry 14; для 13 пройдені перевірки даних і автономні тести, живий імпорт ще не підтверджено.

Типова поведінка:

- вставили посилання **5e.tools** (`https://5e.tools/spells.html#fireball_phb`) — імпортується англійський оригінал;
- вставили посилання **1d20.com.ua** (`https://1d20.com.ua/spells/fireball-xphb/`) — імпортується та сама сутність з українською назвою й описом.

Режим можна змінити в налаштуваннях: «Завжди» перекладає будь-який імпорт Plutonium (зокрема з його власного імпортера), «Ніколи» вимикає автоматичний переклад. Ручні дії доступні незалежно від цього режиму.

У меню **⋮** аркуша закляття, предмета чи здібності та в контекстному меню запису в чарнику доступні **«Перекласти українською»** / **«Повернути оригінал»**. Повернення відновлює збережені назву й опис; механіки, ефекти та використання не змінюються. Назви перекладаються відповідно до налаштування «Назви предметів».

У меню **⋮ чарника → «Перекласти все»** перекладаються всі доступні записи цього персонажа. Вже перекладені записи пропускаються. Потрібні права власника; заблоковані компендіуми не змінюються. Якщо в каталозі 1d20 немає відповідного перекладу або запис не має метаданих Plutonium, модуль повідомляє про це. Окремі класові здібності, для яких немає пакета перекладу, залишаються оригінальними.

**⋮ чарника → «Доповнити закляття класів»** додає відсутні непідготовлені закляття друїда, клірика, паладіна, винахідника та список замін слідопита 2024. Доступні кола визначаються за рівнем конкретного класу. Поточна підготовленість зберігається; замовляння й повний список чарівника не додаються. Під час нового імпорту персонажа таке доповнення виконується автоматично.

## Що перекладається

| Сторінка 5e.tools | Пакет 1d20 | Що змінюється |
|---|---|---|
| spells | `spells` | назва, опис (разом з «На вищих рівнях») |
| items | `items` | назва, опис |
| feats | `feats` | назва, опис |
| optionalfeatures | `optionalfeatures` | назва, опис |
| backgrounds | `backgrounds` | назва, опис |
| races | `races` | назва, опис (лише базові раси; підраси поки ні) |

Істоти (bestiary) поки не перекладаються: їхній текст у Foundry розкиданий по вкладених предметах і потребує окремого мапінгу.

Ключ зіставлення — та сама пара `name_en + source`, яку Plutonium зберігає у `flags.plutonium.hash`. Однакові назви з різних джерел (PHB та XPHB) розрізняються правильно.

## Як це працює

1. Посилання 1d20 (`/spells/fireball-xphb/`) перетворюється на сутність 5etools: за slug у пакеті 1d20 знаходяться `name_en` і `source`, з них будується той самий хеш, що й у 5e.tools (`fireball_xphb`). Для бестіарію використовується легший каталожний індекс. Модуль запам'ятовує, що цей імпорт треба перекласти.
2. Plutonium створює документ через свій звичайний імпортер.
3. Модуль перехоплює `preCreateItem`, знаходить переклад і підміняє `name` та `system.description.value` ще до запису в базу. Якщо потрібний пакет ще не завантажено, документ створюється англійською і оновлюється одразу після завантаження.
4. У `flags.1d20-ua-plutonium` зберігаються англійська назва, slug, посилання на сторінку 1d20 та оригінальні назва й опис (для відкату).

Дані запечені в модуль (тека `data/`, ~14 МБ) і читаються з неї через `data/manifest.json`; автооновлення з сайту немає. Пакети кешуються в Cache Storage браузера з прив'язкою до `sha1` кожного файла, тож після оновлення теки перечитуються лише змінені. У режимі «Завжди» пакети заклять, рис, додаткових особливостей і предметів підвантажуються у фоні через кілька секунд після входу у світ; у режимі «За посиланням» пакет читається при першій вставці посилання відповідного типу.

Записи без повного тексту (у пакеті є лише `summary`) отримують українську назву, а англійський опис лишається, до нього додається лише посилання на сторінку 1d20.

## Налаштування

- **Коли перекладати** — `За посиланням` (типово), `Завжди` або `Ніколи` (світ).
- **Назви предметів** — `Українська`, `Обидві` («Вогняна куля (Fireball)») або `Англійська` (перекладається тільки опис). Англійська назва завжди є у прапорцях, тож автоматизації, які шукають предмет за англійською назвою, можуть на неї спиратися.
- **Клікабельні кидки в описах** — `8к6` перетворюється на `[[/r 8d6]]{8к6}`.
- **Посилання на джерело** — у кінець опису додається «Український переклад: 1d20.com.ua» з посиланням на сторінку сутності.
- **Адреса джерела даних** — типово запечені дані `modules/1d20-ua-plutonium/data`. Можна вказати власне доступне браузеру дзеркало пакетів; якщо його не вдасться дістати, модуль повертається до запечених.
- **Вставляти посилання для імпорту** — налаштування клієнта.

## Запечені дані та їх оновлення

У `data/` лежать: `manifest.json`, пакети перекладів `uk/{spells,items,feats,optionalfeatures,backgrounds,races}.json` і каталожний індекс `index/bestiary.json` (для посилань на істот). Дані від 13.10.2026 за київським часом, формат 1, версія `a64f011725f3`.

Оновити з сайту: створіть у корені модуля `.env` з партнерським ключем в одному рядку (сам ключ або `DND_PARTNER_KEY=ключ`), потім виконайте:

```bash
node modules/1d20-ua-plutonium/tools/mirror.mjs
```

Скрипт звертається до `https://1d20.com.ua/wp-json/dnd/v1/data` з ключем у заголовку Authorization, качає лише файли, у яких змінився `sha1`, звіряє їх із маніфестом і переписує `data/manifest.json`. Пакет із повним текстом ніколи не замінюється пакетом, де є лише `summary` (такий формат сайт віддавав кілька хвилин 18.09.2026); `--force` знімає цей запобіжник.

Стара публічна адреса `/wp-content/uploads/dnd-data` більше не працює. Партнерський ключ використовує лише скрипт оновлення; браузерний модуль читає готові локальні пакети. `.env` не включайте до архіву модуля чи репозиторію.

## Вставка посилань

Скопіюйте посилання на кшталт `https://5e.tools/spells.html#fireball_phb` (оригінал) або `https://1d20.com.ua/spells/fireball-xphb/` (переклад) і натисніть Ctrl+V:

- над відкритим аркушем персонажа — закляття, предмети, риси, додаткові особливості, передісторії та раси імпортуються прямо на нього;
- будь-де інде (наприклад, над бічною панеллю) — у директорію світу за правилами тек Plutonium; істоти завжди імпортуються у світ.

Кілька посилань в одній вставці імпортуються по черзі, можна змішувати обидва сайти. Вставка у текстові поля й редактори не перехоплюється.

Підтримувані розділи 1d20: `spells`, `items`, `feats`, `optionalfeatures`, `backgrounds`, `races`, `bestiary` (істоти імпортуються без перекладу).

Якщо запечені дані відстали від сайту і slug з посилання в них відсутній, модуль відновлює англійську назву та джерело з самого slug (правило: нижній регістр, апострофи викидаються, решта неалфавітних символів стає дефісом), знаходить сутність у даних 5etools, які завантажив Plutonium, і імпортує англійський оригінал з повідомленням про це.

## API

```js
const api = game.modules.get('1d20-ua-plutonium').api;

await api.translateItem(item);            // перекласти існуючий предмет
await api.translateActor(actor);          // усі предмети актора
await api.translateWorld();               // усі предмети світу та акторів світу
await api.translateItem(item, {force: true}); // перезаписати вже перекладений
await api.revertItem(item);               // повернути англійські назву та опис
await api.data.refresh();                 // скинути кеш і перечитати маніфест
api.data.getDataInfo();                   // версія даних, джерело, завантажені пакети
api.requestTranslation('spells', 'fireball_xphb'); // перекласти наступний імпорт цієї сутності (режим «За посиланням»)
```

## Умови використання даних

Дані надано 1d20.com.ua. В описі модуля має бути рядок «Український переклад: 1d20.com.ua», посилання на сайт у перекладах не вирізаються. Перед публікацією модуля попередьте власника сайту.
